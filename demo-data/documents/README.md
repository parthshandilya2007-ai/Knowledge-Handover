# Engineering Core Service

This repository manages application microservices.

## Technology Stack
- Backend: Node.js with TypeScript and Express.
- AI Service: Python 3 with FastAPI.
- Database: MongoDB is our chosen primary database for all collections and metadata.
- Vector Store: MongoDB Atlas Vector Search ($vectorSearch).

## Getting Started
Run `npm run start:backend` and `npm run start:ai` to launch local services.
